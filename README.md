Cum se descarcă și folosește aplicația pe alt calculator

1. Instalează programele necesare

- Node.js - Descarcă de aici: https://nodejs.org/
- Git - Descarcă de aici: https://git-scm.com/
- Expo CLI - Deschide Command Prompt și rulează: npm install -g @expo/cli

2. Descarcă aplicația

1. Deschide Command Prompt
2. Navighează unde vrei să salvezi aplicația: cd Desktop
3. Descarcă aplicația: git clone https://github.com/AndreiPana12/DriverCompanion.git
4. Intră în folderul aplicației: cd DriverCompanion/testing

3. Instalează dependențele

npm install

4. Pornește aplicația

npx expo start

5. Testează pe telefon

1. Instalează Expo Go din Play Store sau App Store
2. Scanează codul QR din terminal
3. Aplicația se va deschide pe telefon
